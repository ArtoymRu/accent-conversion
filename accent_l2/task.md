План эксперимента: Анализ и факторизация акцентной информации в дискретных представлениях речи
1. Цель эксперимента
Основная цель — исследовать, как дискретные представления речи, полученные с помощью моделей HuBERT, EnCodec и WavLM, кодируют информацию об акценте говорящего. Мы стремимся:

1	Факторизовать (разделить) лингвистическое содержание и информацию об акценте с помощью разреженных автоэнкодеров (Sparse Autoencoders, SAE) (пока это гипотеза, может и не получиться).
2	Выявить и охарактеризовать признаки (features) в SAE, которые специфичны для разных акцентов.
3	Сравнить модели HuBERT, EnCodec и WavLM по их способности к разделению акцентной информации.
4	Оценить принципиальную возможность управления акцентом путем манипуляции выученными признаками.

2. Данные и инструменты
2.1. Датасет
•	Название: L2-ARCTIC
•	Описание: Корпус английской речи, записанный носителями 7 разных языков (арабский, хинди, корейский, мандарин, испанский, турецкий, вьетнамский). Содержит параллельные записи, что идеально подходит для анализа акцентов.
•	Ссылка для скачивания: https://psi.engr.tamu.edu/l2-arctic-corpus/

2.2. Предобученные модели
HuBERT (Base): Основная модель для первоначальных экспериментов.
EnCodec: Модель для сравнения, ориентированная на сжатие аудио.
WavLM: Модель для сравнения, обученная на более разнообразных данных.
3. Этапы эксперимента
Этап 1: Подготовка окружения и данных 
Клонировать репозиторий AudioSAE:
Скачать и распаковать датасет L2-ARCTIC:
◦	Создать директорию /data/l2_arctic.
◦	Скачать все записи для всех дикторов.
◦	Организовать файлы по папкам, соответствующим акцентам (например, /data/l2_arctic/arabic, /data/l2_arctic/hindi и т.д.).
Подготовить скрипт для загрузки данных: Написать простой загрузчик данных на PyTorch (torch.utils.data.Dataset), который будет возвращать аудио-фрагменты и метку акцента.

Этап 2: Извлечение скрытых представлений 
Загрузить предобученную модель HuBERT: Использовать библиотеку transformers от Hugging Face.
Написать скрипт extract_features.py, который:
◦	Проходит по всему датасету L2-ARCTIC.
◦	Для каждого аудиофайла извлекает скрытые представления (hidden states) из нескольких слоев модели HuBERT (например, слои 6, 9, 12).
◦	Сохраняет представления на диск в формате .pt или .npy вместе с информацией об акценте и пути к исходному файлу. Это ускорит последующие эксперименты.

Этап 3: Обучение разреженных автоэнкодеров (SAE)
Адаптировать конфигурацию обучения из репозитория AudioSAE:
◦	Указать путь к извлеченным на предыдущем шаге представлениям.
◦	Настроить гиперпараметры SAE: коэффициент разреженности (sparsity coefficient), размер словаря (dictionary size), коэффициент расширения (expansion factor). Рекомендуется начать с параметров, указанных в статье AudioSAE.
Обучить по одному SAE для каждого выбранного слоя HuBERT.
◦	Например, hubert_layer6_sae, hubert_layer9_sae, hubert_layer12_sae.
◦	Процесс обучения может занять несколько часов на GPU.

Этап 4: Анализ и интерпретация признаков SAE
Это самый творческий и важный этап.

Анализ специализации признаков (Feature Specialization):
◦	Для каждого SAE и каждого акцента в датасете посчитать, как часто активируется каждый признак (feature).
◦	Задача: Найти признаки, которые активируются значительно чаще для одного акцента по сравнению с другими.
◦	Визуализация: Построить тепловую карту (heatmap), где по оси X — признаки SAE, по оси Y — акценты, а цвет ячейки — частота активации. Это наглядно покажет "акцентные" признаки.
Качественный анализ: 
◦	Написать скрипт, который находит аудио-фрагменты, максимально активирующие определенный "акцентный" признак.
◦	Прослушать эти фрагменты, чтобы понять, какой именно аспект произношения (интонация, произношение гласных/согласных) захватывает данный признак.
Классификация акцентов: 
◦	Обучить простой линейный классификатор (например, логистическую регрессию) поверх разреженных представлений, полученных из SAE.
◦	Задача: Оценить, насколько хорошо акцент предсказывается по этим признакам. Высокая точность будет означать, что SAE успешно извлекли акцентную информацию.
◦	Сравнить точность для разных слоев HuBERT.

Этап 5: Сравнение моделей 
Повторить этапы 2-4 для моделей EnCodec и WavLM.
Сравнить результаты:
◦	У какой модели "акцентные" признаки более выражены и стабильны?
◦	Какая модель дает наилучшую точность в задаче классификации акцентов?
◦	Сравнить тепловые карты специализации признаков для всех трех моделей.

4. Требования к результатам и графикам
По итогам эксперимента необходимо подготовить отчет, включающий следующие материалы:

Таблица 1: Сравнение моделей
◦	Строки: HuBERT (слой 6, 9, 12), EnCodec, WavLM.
◦	Столбцы: Качество реконструкции (MSE), Разреженность (L0-норма), Точность классификации акцентов (Accuracy/F1-score).
График 1: Тепловая карта специализации признаков
◦	Для лучшей из моделей (например, HuBERT-12) показать heatmap, где видно, какие признаки "загораются" на каких акцентах.
График 2: Кривые обучения SAE
◦	Показать зависимость потерь реконструкции и разреженности от итерации обучения.
Аудио-примеры: 
◦	Подготовить несколько пар аудио-примеров:
•	Оригинальный звук.
•	Звук, реконструированный из представлений SAE.
•	(Опционально) Звук, где "акцентный" признак был искусственно усилен или подавлен.

Основной ботл нек для нас – это выложат ли ребята код SAE (чтобы не брать другую, не гарантирующую резульат) и хватит ли возможностей gpu нормально дообучить.
